# Magento / Adobe Commerce V1 Product Field Contract & Runtime Audit

**Contract version:** `1.0.0`
**Repository base:** `54815f4fc09221ff623871d6cdb3f32870bd079a`
**Evidence retrieval/audit date:** `2026-08-28`
**Applicability:** Adobe Commerce and Magento Open Source 2.4.x Admin REST; installation-specific EAV metadata must be discovered from the target installation and attribute set.

> **Authority rule.** The adjacent `magento_v1_product_field_matrix.json` is the authoritative field-by-field and backlog dataset. This document is its human-readable audit. `MagentoV1ProductFieldMatrixTest` prevents missing keys, invalid statuses, duplicate identities, unconditioned installation-dependent rows, unblocked partial/unsupported rows, stale normalizer coverage, stale Safe Sync allowlists, and omission of a JSON row from this document.

## Scope and contract layers

- **A — Core/static Product:** the `ProductInterface` envelope and repository fields such as SKU, name, status, visibility and base price.
- **B — EAV attributes:** an open, installation/attribute-set-dependent set discovered from product attribute metadata. This matrix deliberately does not claim a universal custom-attribute list.
- **C — Extension/type-specific:** configurable options/children, media, category links, pricing matrices, MSI inventory and module-defined extension attributes. These are structures or domain relations, not arbitrary Product columns.

## Discovery audit

### Accepted and rejected `frontend_input` values

`AdobePaaSAttributeNormalizer::mapFrontendInput()` currently accepts exactly: `text`, `textarea`, `texteditor`, `date`, `datetime`, `boolean`, `select`, `multiselect`, `price`, `media_image`, `gallery`, and `weight`. It maps these to the platform canonical types `text`, `long_text`, `date`, `datetime`, `boolean`, `select`, `multi_select`, `money`, `image`, `image_collection`, and `number`. Any other non-null value fails with `UnmappedValue`; a narrowly defined system/service-only record is skipped only when `frontend_input=null`, `is_user_defined=false`, `is_visible=false`, and its attribute code is valid.

The catalog Fixed Product Tax input `weee`, and any additional values introduced by installed modules, therefore fail closed today. This is safer than guessing, but it is not full EAV discovery coverage. The smallest correction is an explicit source/target-fixture-backed mapping per value, with no generic string fallback.

## Ownership, Preview, Receive and Safe Sync findings

- **Ownership:** Product owns shared descriptive identity; ProductVariant owns sellable SKU identity; dynamic values use FieldDefinition/FieldBinding and separate product/variant value stores; relations remain relations; Pricing, Availability, Media and Category data stay with their existing domains; connector execution settings own `attribute_set_id`, Magento type and visibility projection; ExternalRecordLink owns account-scoped Magento entity identity.
- **Preview/export:** scalar mapped product/variant fields, requiredness, single-select option resolution, simple products, configurable dimensions/children, resolved base price, lifecycle/visibility projection and internal media operations are represented. Multiselect, categories, MSI, advanced prices and arbitrary nested extension attributes are not represented.
- **Receive/import:** the foundations are broader than the current Apply slice, but the Adobe proposal service currently emits one `name` candidate. This audit does not mislabel other platform owners as absent; it records the missing Adobe candidate/read/routing seam.
- **Safe Sync READ:** entity-bound identity verification returns identity and name; it does not expose mapped attributes, price, media, categories, inventory, configurable relations or nested structures.
- **Safe Sync WRITE:** the request allowlist is `expected_sku` (identity precondition), `name`, `status`, `visibility`, `price`, plus scalar string `mapped_attributes`. SKU is a precondition, not writable. Media is explicitly excluded from product save. Multivalue, configurable structure, category relations, inventory and nested structures have no representation.
- **Capability truth:** `AdobePaaSConnectorAdapter` continues to return true only for Products/Export/Preview. Products/Export/Live remains false. This audit changes no support flag and is not target certification.
