## Frozen desktop empty-state geometry and visual hierarchy

1. The outer full-width section is titled **Медіа** (no extra marketing headline).
2. Inside it, exactly one roomy, light, dashed, rounded rectangular area with visually balanced inner spacing. No second FilePond box/border and no detached selector button.
3. Centered gray image-plus icon, then bold **Перетягніть зображення сюди**.
4. A lighter centered subtitle: **або скористайтеся одним зі способів додавання**.
5. One centered **horizontal row of three independently operable buttons** at a desktop width: image-upload icon + **Завантажити**, library icon + **Обрати з медіатеки**, link icon + **Додати за URL**. Buttons share outline, corner radius, typography, height, and hover/focus treatment.
6. A centered hint under those buttons: **JPEG, PNG, GIF, WebP, AVIF · до 20 МіБ / 25 МП**.
7. No overlapping labels or large gaps caused by absolutely positioned invisible/selected FilePond elements. The screenshot must show the *full* outer section, not just an isolated clickable button.

**Critical root cause already demonstrated in code:** Filament EditRecord defaults to a two-column root form. The outer `Section::make()->schema(...)` was a half-width grid cell, so at a 1440px DESKTOP viewport the Media region was only ~468px wide and switched to mobile styling. The native **`->columnSpanFull()` on the outer Brand section** fixes the containing form grid. Do not compensate by shrinking fonts or overriding FilePond internals.

## Approved behavior; no fake controls

- Native FilePond must open the actual file chooser by clicking `Завантажити` and accept drag/drop in the FULL visible dashed area. Browser must verify processing completion and Save persistence.
- `Обрати з медіатеки` must open the existing MediaAsset picker, with original-only, Workspace-scoped selection. Brand allows exactly one selected original; choosing a second deselects the first before confirmation.
- `Додати за URL` must open the native URL form and ingest safely via existing SSRF-bounded transport + canonical OriginalImageIngestService, not hot-link or decorative modal.
- Loading/error/selected-image state must preserve accessible controls and readable previews, rather than turning the whole section into a FilePond progress slab.
- At narrow **container** widths, buttons may wrap or stack vertically with sufficient touch area; proportional fonts and the same visual language stay unchanged. Do not use desktop viewport width to decide when an embedded drawer is narrow.
- User-visible texts localized UK/RU/EN. No external model/database state changes, no second MediaAsset owner.
